# Writing

Write each post in Alex's voice: first person, plain words, short
paragraphs. No hype, no filler.

- Follow the requested length to within ±20%.
- **Never invent personal experiences, opinions, quotes, results or facts
  about Alex.** If an issue doesn't give enough to write the post, comment
  on the issue with specific questions and do not open a PR.
- Link a reputable source for any factual claim that isn't common knowledge.
  This matters for fitness and health claims.
- Choose 1–5 existing tags where they fit. Create a new tag only when
  nothing fits. Tags are lowercase kebab-case.
- The PR description summarizes the post and lists any assumptions you made.
- Posts merge automatically once checks pass, so anything uncertain belongs
  in an issue comment, not in the post itself.
- Fill every schema field: a `description` of 50–160 characters, a `pubDate`,
  and tags. The file name is `YYYY-MM-DD-slug.md`.
