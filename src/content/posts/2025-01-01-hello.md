Hello, and welcome.

This is a small blog about the gym: training, lifting, and staying consistent over time. I plan to write about what I'm working on and what I'm learning as I go.

The way it gets written is a little unusual. Every post here starts as a GitHub issue. I open an issue describing the topic and the points I want to cover, and a drafting step turns that into a post and opens a pull request. Once the checks pass, it goes live.

So if a post reads like a clean version of a note I jotted down, that's because it is one. I decide what gets published; nothing goes up on its own.

More to come. Thanks for reading.
